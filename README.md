## 本地运行

纯静态站点，任意静态服务器即可：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 注意：内容通过 fetch 加载 JSON，请使用 HTTP 服务访问（不要直接双击 index.html）。

## 功能

五 Tab+1 信息架构（双通道设计：主线管节奏、索引管查找）：

- 🗺️ **学习地图**（默认首页）：七关卡技能树，锚点分组、节点点亮，Boss 战 ≥80% 解锁下一关
- 🔎 **知识点索引**：全量 82 点平铺、无门禁、可直达（含未解锁关卡内容）；锚点/标题/关键词实时搜索；关卡/模块/掌握程度/星级🆕/学习状态叠加筛选；锚点顺序或星级降序排序；状态徽章（未开始/学习中/已通过/待复习）；快捷复习（今日待复习/随机考我/高频考点）；筛选条件跨页保留。数据由 `tools/build-index.js` 从最终大纲自动生成（data/index.js 单一来源）
- 📖 **错题本与复习**：1/3/7 天间隔重复，与索引页「待复习」状态、「今日待复习」筛选实时联动
- ⚔️ **Boss 战**：七关计时模拟面试 Hub + 单关战斗；解锁门禁只作用于技能树主线推进
- 🧰 **实战任务卡**：七关里程碑任务卡 Hub + 单卡（步骤指引 + 自查清单 + 参考架构图），无门禁
- 📚 **文档阅读**：纯知识速查页（`#/docs`）——CSNotes 式版式：左侧「关卡→锚点→考点」目录树（当前项高亮、折叠展开），右侧仅知识本体（定义 / 要点 / 面试问法 / 小结），无游戏化与引导元素、不写学习进度；配合 ☀️/🌙 深浅色切换，是快速定位与查阅知识的首选入口

其他：⭐ XP 与七级头衔晋升（庆祝动画）、🎯 锚点标注（编号/建议掌握程度/关键问题，带 * 为选修）、📝 模块回顾测验（自动组卷、纯自测无门禁）、🎓 精通级出题考别人、📈 战绩面板、☀️/🌙 深浅色主题切换（localStorage 持久化）。知识点页支持上一题/下一题（按关卡与锚点顺序）导航。
